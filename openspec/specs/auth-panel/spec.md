# auth-panel Specification

## Purpose
定义欢迎页右侧登录面板的行为：怎么打开、感观如何、两个 tab 之间怎么切、成功后去哪、窄屏与无 JS 怎么降级，以及它为什么不跟随站点主题。

## Requirements

### Requirement: 入口与无 JS 降级

欢迎页 SHALL 提供服务入口打开登录面板；在 JavaScript 不可用时，同一入口 MUST 仍能作为普通链接把用户带到 `/login`。

#### Scenario: 点击打开面板
- **WHEN** 未登录用户点击欢迎页上的「登录」
- **THEN** 面板从右侧滑出，页面不发生跳转

#### Scenario: 禁用 JS
- **WHEN** 浏览器禁用 JavaScript 后点击「登录」
- **THEN** 直接进入 `/login` 页面

### Requirement: 已登录时入口改为账号相关页

已登录用户访问欢迎页时，账号入口 MUST NOT 触发登录面板，且 MUST NOT 与主按钮重复指向文章列表——管理员指向后台，普通用户指向个人资料。

#### Scenario: 管理员访问
- **WHEN** 带着管理员会话打开 `/`
- **THEN** 第三个入口显示「后台」并指向 `/admin`，不弹出面板

#### Scenario: 普通用户访问
- **WHEN** 带着普通账号会话打开 `/`
- **THEN** 第三个入口显示「个人资料」并指向 `/profile`

#### Scenario: 入口不重复
- **WHEN** 已登录访问 `/`
- **THEN** 页面上只有一个指向 `/blog` 的入口（主按钮「进入博客」）

### Requirement: 面板嵌在右栏，不是浮层

登录面板 MUST 以行内区块的形式出现在欢迎页右侧预留的栏位里：无遮罩、不锁页面滚动、不覆盖主内容；打开时焦点进入面板，关闭后焦点回到触发按钮。

#### Scenario: 打开时的位置与焦点
- **WHEN** 点击「登录」
- **THEN** 面板出现在右栏（主内容左侧不变），焦点落在第一个输入框，页面仍可滚动

#### Scenario: 关闭的两种方式
- **WHEN** 点击面板右上角关闭按钮，或按 Esc
- **THEN** 面板从右栏收起，焦点回到「登录」按钮

### Requirement: 登录 / 注册 tab 切换

面板 SHALL 提供登录与注册两个 tab，符合 WAI-ARIA tabs 模式（`role="tab"` / `aria-selected` / 左右方向键切换）；切换时 MUST NOT 丢失已输入的内容。

#### Scenario: 切换 tab
- **WHEN** 点「注册」tab
- **THEN** 指示条滑到注册，登录表单淡出、注册表单淡入，面板高度过渡到新内容的高度

#### Scenario: 输入不丢
- **WHEN** 在登录 tab 填了用户名，切到注册再切回登录
- **THEN** 之前填的用户名仍在

#### Scenario: 键盘切换
- **WHEN** 焦点在 tab 上按左右方向键
- **THEN** 焦点与选中态一起移动，内容随之切换

### Requirement: 登录成功后离开面板

登录或注册成功后，面板 SHALL 自动收起并跳转到 `/blog`，同时让页头的登录态刷新。

#### Scenario: 登录成功
- **WHEN** 凭据正确并提交
- **THEN** 面板收起并进入 `/blog`，页头显示已登录的账号菜单

#### Scenario: 登录失败
- **WHEN** 凭据错误
- **THEN** 面板保持打开、已填内容保留，并用现有弹窗提示失败原因

#### Scenario: 注册成功
- **WHEN** 注册接口返回成功并自动登录
- **THEN** 与登录成功一致：收起面板并进入 `/blog`

### Requirement: 切换与开合的动效

面板 SHALL 用动画交代状态变化：打开时遮罩淡入 + 面板从右侧推入，切换 tab 时指示条位移且内容横向交叉，关闭时反向收回；所有位移与时长在 `prefers-reduced-motion: reduce` 下取消。

#### Scenario: 正常动效
- **WHEN** 打开面板并切换一次 tab
- **THEN** 遮罩淡入、面板推入、指示条滑动、表单横向交叉、面板高度平滑变化，动画期间不出现内容跳动或滚动条抖动

#### Scenario: 减弱动效
- **WHEN** 系统开启减少动态效果
- **THEN** 面板与内容直接切换，无位移与淡入淡出

### Requirement: 面板沿用欢迎页的视觉，不跟随站点主题

面板 SHALL 使用欢迎页的白色赛博 token（纸色、发丝线、电蓝、洋红），`<html data-theme>` 在六套主题间切换时面板外观不变；同时与页面的 HUD 角标、扫描线语言一致，不使用圆角卡片。

#### Scenario: 主题切换
- **WHEN** 把站点主题从「赛博青」切到「晨光白」后刷新 `/`
- **THEN** 面板的底色、描边与强调色保持一致

### Requirement: 窄屏堆叠

视口宽度不超过 980px 时，页面 MUST 改为单列：面板落到文案下方并占满可用宽度，不出现横向溢出。

#### Scenario: 手机上打开
- **WHEN** 在 390px 宽的视口点击「登录」
- **THEN** 面板出现在文案下方、宽度自适应，表单与按钮完整可见，页面无横向滚动条
