# welcome-motion Specification

## Purpose
定义欢迎页动效层的行为：入场序列怎么编排、指针类效果在什么条件下启用、幅度上限是多少、点击离开时发生什么，以及减弱动效与无 JS 两种情况下页面必须仍然完整可用。

## Requirements

### Requirement: 入场序列由一条 timeline 编排

页面首次加载时 SHALL 按固定顺序播放一次入场（标记描边 → 光标块 → 字标逐字揭示 → 定位句自下而上遮罩揭示 → 状态行 → 入口），总时长不超过 1.8 秒，且 MUST NOT 随滚动或指针再次触发。

#### Scenario: 首次进入
- **WHEN** 打开 `/`
- **THEN** 元素按上述顺序出现，1.8 秒内全部就位，之后滚动或移动鼠标不会重播入场

#### Scenario: 顺序可辨
- **WHEN** 观察入场
- **THEN** 字标在标记之后开始、定位句在字标结束后开始，相邻环节有可感知的错峰而不是同时淡入

### Requirement: 无 JS 时内容完整可见

入场前的初始隐藏态 MUST 以"JS 已就绪"为条件。禁用 JavaScript 时，标记、字标、定位句、状态行与三个入口 MUST 全部可见可用。

#### Scenario: 禁用 JS
- **WHEN** 浏览器禁用 JavaScript 打开 `/`
- **THEN** 页面直接呈现最终状态，没有元素停留在透明或位移状态

#### Scenario: 脚本加载失败
- **WHEN** GSAP 因网络或脚本错误未能执行
- **THEN** 内容在无动画的情况下可见，页面不出现空白区

### Requirement: 光标跟随仅在精确指针设备启用

指针落在一个可点元素上时，跟随光标的环 SHALL 放大并改变描边；该效果 MUST 只在 `(hover: hover) and (pointer: fine)` 成立时启用，且 MUST NOT 拦截点击或改变元素命中区域。

#### Scenario: 桌面鼠标
- **WHEN** 在桌面浏览器移动鼠标
- **THEN** 环形光标平滑跟随（有明显但不拖沓的延迟），悬停在按钮与链接上时放大

#### Scenario: 触屏设备
- **WHEN** 在触屏或 `hover: none` 的设备上打开页面
- **THEN** 不渲染跟随光标，页面其余部分正常

### Requirement: 磁吸只作用于主要入口且幅度受限

主要按钮与次要链接 SHALL 在指针进入其感应范围时向指针方向位移，离开后回弹；位移 MUST NOT 超过 10px，且 MUST NOT 改变元素的可点击区域或键盘焦点行为。

#### Scenario: 悬停磁吸
- **WHEN** 指针移入按钮感应区
- **THEN** 按钮产生小幅位移与回弹，指针离开后回到原位

#### Scenario: 键盘不受影响
- **WHEN** 用 Tab 聚焦按钮并按 Enter
- **THEN** 触发跳转，行为与未启用磁吸时一致

### Requirement: 鼠标视差幅度极小

背景网格与标记 SHALL 随指针位置产生不超过 6px 的位移；状态行、定位句与按钮 MUST NOT 参与视差，以保证文字始终稳定可读。

#### Scenario: 视差边界
- **WHEN** 指针从视口一端移到另一端
- **THEN** 网格与标记的位移始终在 6px 以内，正文文字不移动

### Requirement: 出页过渡

点击「进入博客」SHALL 先播放一段不超过 600ms 的过渡，再执行跳转到 `/blog`；在减弱动效或无 JS 的情况下 MUST 直接跳转。

#### Scenario: 正常点击
- **WHEN** 点击主按钮
- **THEN** 过渡播完后进入 `/blog`

#### Scenario: 减弱动效
- **WHEN** 系统开启减少动态效果后点击主按钮
- **THEN** 不播放过渡，立即进入 `/blog`

### Requirement: 减弱动效时全部关闭

`prefers-reduced-motion: reduce` 成立时，入场、光标跟随、磁吸、视差与出页过渡 MUST 全部不执行，页面直接以最终状态呈现。

#### Scenario: 减少动态效果
- **WHEN** 系统开启该偏好打开 `/`
- **THEN** 没有任何位移、描边或跟随动画，内容立刻可见，链接照常跳转

### Requirement: 动效不损害可读性与无障碍语义

装饰性元素（跟随光标、网格视差层）MUST 对辅助技术隐藏且不可聚焦；动效 MUST NOT 造成布局位移（不改变文字位置导致重排），焦点环仍清晰可见。

#### Scenario: 屏幕阅读器
- **WHEN** 屏幕阅读器读取页面
- **THEN** 不会读到跟随光标或视差层，标题、定位句与链接语义不变

#### Scenario: 键盘焦点
- **WHEN** 用 Tab 遍历
- **THEN** 焦点顺序与视觉顺序一致，焦点环不被自定义光标遮挡或替换
