# Design

## Context

- 现有首页 `/` 是账本（`app/page.tsx`）：一句定位、按日期倒排的文章行、右侧题跋栏。它服务"常来的人"，但没有门面作用。**实施时按最新要求调整了路由**：欢迎页放到 `/`，账本搬到 `/blog`。
- 站点有六套主题（`<html data-theme>`），靠 `globals.css` 的 CSS 变量驱动；`redesign.css` 是视觉层。两处都有 `.shell`（1160px）、发丝线语言（`--rule`）与细网格背景（`body::before`）。
- 站点已有标记：`public/favicon.svg` 是"终端提示符"——青色 caret + 品红光标块。这是全站唯一的图形资产，欢迎页直接把它放大使用，不另造图形。
- 动效方面，项目已有 GSAP（`GsapReveal`），但欢迎页只需要一段固定的入场序列——纯 CSS keyframes 就能完成，不必为此加载 GSAP。

## 设计计划

### 色彩（6 个命名色）

| Token | 值 | 用途 |
| --- | --- | --- |
| `--w-paper` | `#FBFCFD` | 纸面：比纯白低半档、偏冷，避免刺眼也避开暖奶油底 |
| `--w-ink` | `#0B0E12` | 字标与标题 |
| `--w-mute` | `#59636F` | 定位句、状态行、次链接 |
| `--w-line` | `#DCE3EB` | 发丝线与非交互描边 |
| `--w-signal` | `#0F62FE` | 电蓝：主按钮、焦点环、caret 笔画 |
| `--w-signal-2` | `#D81653` | 洋红：光标块、链接悬停下划线 |

用色纪律：**霓虹只落在"可以点的东西"和标记的两笔上**。标题、正文、状态行一律墨色与中性灰；页面上没有任何发光、渐变底或色块。

### 字体（沿用站点的两把嗓子）

- **等宽（机器）**：字标、状态行、次链接、按钮文字。`LZW.LOG` 用 0.22em 字距、中号字重——它是标题级排版元素，不是标签。
- **无衬线（人）**：那句定位。`clamp(1.5rem, 2.6vw, 2.05rem)`、行高 1.65、最宽 22em。

不引入 webfont：站点现在是系统字体栈，加一个 300KB 的拉丁字体只为一行字不划算，而且中英混排时反而更不协调。

### 布局

左对齐，落在与首页相同的 1160 shell 左边缘；垂直方向在页头页脚之间居中。右侧留白不填东西——那正是"克制"。

```
┌ header ─────────────────────────────────────────┐
│                                                  │
│                                                  │
│   ❯_                     ← 标记 96px（装饰）      │
│   LZW.LOG                ← 字标 mono 3.2rem      │
│                                                  │
│   记录开发中的判断与失误，偶尔写点别的。            │  ← 定位句
│   ──────────                                     │  ← 发丝线 6rem
│   2 篇文章   6 个在用标签   更新于 2026.11.05      │  ← 状态行 mono .72rem
│                                                  │
│   [ 进入博客 ]   标签   登录                       │
│                                                  │
└ footer ─────────────────────────────────────────┘
```

对齐：全部左对齐（与账本页一致），不做居中构图；元素之间用 1.5 / 2 / 2.6rem 的三档间距。

### 原则

1. **放大"是什么"，不是"有多少"。** 门面上唯一的视觉重量是站点标记与字标，文章数量只在状态行里安静地报一次。
2. **霓虹是交互的信号，不是气氛。** 只有主按钮、焦点环、链接悬停和标记两笔能带电。
3. **一次入场，一次呼吸。** 入场序列只播一次；之后唯一的动作是光标 1.2 秒步进闪烁。
4. **与站点同源。** 同一套 shell 宽度、同一根发丝线、同一个标记、同一条"等宽说机器 / 无衬线说人"的规则。
5. **没有 JS 也是完整的。** 全部内容服务端渲染，动效只是锦上添花。

### 对照"通用默认"自查

| 常见默认 | 这里怎么做 |
| --- | --- |
| 暖奶油底 + 高对比衬线 + 陶土色 | 冷白纸面 `#FBFCFD`，无衬线 + 等宽，电蓝/洋红 |
| 近黑底 + 单一酸绿/朱红 | 反过来了：白底，且强调色只用于交互 |
| 报纸式密集发丝线栏 | 只用一根 6rem 短线做"状态行之前的分隔"，不做多栏 |
| SaaS 卡片套件 | 页面上零卡片、零圆角大盒子、零投影 |
| 全大写眉标 / 中点拼接元信息 / 文案后跟 → | 没有眉标；状态行用空白与间距分隔，不用 `·`；按钮不挂箭头 |

自我删减：原本还打算加一条缓慢横扫的扫描线，删掉了——它与光标闪烁重复，属于"两个呼吸"。保留**标记 + 一次入场**作为唯一记忆点。

## 实现决策

### D0. 路由：`/` 是欢迎页，列表搬 `/blog`，`/welcome` 用 301 收口

- `app/welcome/page.tsx` 的内容移到 `app/page.tsx`；原 `app/page.tsx` 的账本整体移到 `app/blog/page.tsx`（文件搬家，不改内容）。
- `/welcome` 不再有页面文件，改由 `next.config.ts` 的 `redirects()` 输出 `statusCode: 301` 到 `/`。用配置而不是 `permanentRedirect()`：后者发 308，而这里要的是 301，且配置层不会多渲染一次页面。
- 所有"返回首页"语义的内部链接改为指回列表（`/blog`）：文章页、标签索引、标签详情、登录页、注册页、个人资料页，文案统一成「← 返回文章列表」。后台侧栏的「返回前台」仍指 `/`（它就是前台首页）。
- 页头导航从「首页 / 标签」变成「首页 / 文章 / 标签」，并让 `/posts/<slug>` 也点亮「文章」。

### D0b. 门面不挂站点头尾：用 route group 拆外壳，不用 CSS 遮

初版把欢迎页放在 `/welcome` 但让它继承了全局页头页脚，等于门面上挂了个"返回首页"——这是判断错误，已纠正。

- 拆分方式：`app/layout.tsx` 只保留文档外壳（`<html>`、`<body>`、主题初始化脚本、全局样式）；站点页头/页脚/`FeedbackProvider` 下沉到 `app/(site)/layout.tsx`。`admin`、`blog`、`login`、`posts`、`profile`、`register`、`tags` 七个路由目录整体移进 `(site)`（URL 不变），根路径的 `app/page.tsx` 留在分组外。
- 为什么不用 CSS：`body:has(.page-welcome) .site-header { display: none }` 能藏住，但 DOM 里仍然生成页头（`HeaderAuth` 还会打 `/api/me`）、且依赖 `:has()`。route group 是结构上的"没有"，不是"看不见"。
- 代价：`/` 的高度从 `calc(100dvh - 7.5rem)` 变成整屏 `100dvh`；`body:has(.page-welcome)` 那几条针对页头页脚的配色覆盖随之删除（它们已成死代码）。

### D1. 服务端组件 + 一段 CSS，零客户端 JS

`app/welcome/page.tsx` 是纯服务端组件，`export const revalidate = 60`（与首页一致）。动效全部由 CSS keyframes + `animation-delay` 完成，不引入 GSAP、不写 `"use client"`。代价是动效只能做"固定序列"，但这正是需求。

### D2. 样式隔离：`.page-welcome` 作用域 + 自带网格

- 所有规则前缀 `.page-welcome`，变量定义在其内部，**不出现任何 `[data-theme]` 选择器**。因此切换主题时它不受影响。
- 站点全局网格是 `body::before`（用主题强调色画），在欢迎页上会跟着主题变，所以用 `body:has(.page-welcome)::before { display: none }` 关掉它，改由 `.page-welcome` 自己用 `--w-line` 画一层 0.5% 浓度的细网格。`:has` 不支持时最多是多一层很淡的主题网格，不影响可读性。

### D3. 标记组件复用 favicon 的图形

`components/BrandMark.tsx`：内联 SVG（caret 路径 + 光标块），颜色取自 `--w-signal` / `--w-signal-2`，`aria-hidden="true"`。尺寸 `clamp(64px, 9vw, 104px)`。描边动画靠 `stroke-dasharray` / `stroke-dashoffset`。

### D4. 入场序列（总时长 ~1.2s）

| 顺位 | 元素 | 动作 | 延迟 | 时长 |
| --- | --- | --- | --- | --- |
| 1 | 细网格 | 透明度 0 → 1 | 0 | 700ms |
| 2 | 标记 caret | 描边绘出 | 120ms | 600ms |
| 3 | 标记光标块 | `scaleX` 0 → 1（`transform-origin: left`） | 620ms | 180ms |
| 4 | 字标 | 逐字上移 10px + 淡入，间隔 22ms | 720ms | 420ms |
| 5 | 定位句 / 发丝线 / 状态行 / 入口 | 上移 8px + 淡入，间隔 80ms | 880ms 起 | 480ms |

`@media (prefers-reduced-motion: reduce)`：所有动画 `animation: none`，并显式写死最终态（`opacity: 1; transform: none; stroke-dashoffset: 0`），保证减少动效时也看到完整页面。

### D5. 文案

- 字标：`LZW.LOG`
- 定位句：**记录开发中的判断与失误，偶尔写点别的。**
- 状态行：`{N} 篇文章`、`{M} 个在用标签`、`更新于 {YYYY.MM.DD}`
- 主按钮：**进入博客**（→ `/`）；次入口：**标签**（→ `/tags`）、**登录**（→ `/login`）
- 空站降级：`新站刚开张，还没有文章` 替代三个计数

### D6. 高度与外壳

保留全局页头页脚。内容区 `min-height: calc(100dvh - 7.5rem)`（页头 3.75rem + 页脚约 3.75rem），并双写 `100vh` 回退；内容超出时正常纵向滚动，不做裁切。

## Risks / Trade-offs

- [`body:has()` 在老浏览器不生效] → 只影响背景网格的"主题色残留"，内容与可读性不受影响；已在设计里接受。
- [`100dvh` 兼容性] → `min-height: 100vh` 先行、`100dvh` 覆盖，两级回退。
- [字标用 0.22em 字距的等宽字体，Windows 下 Cascadia/Consolas 宽度差异可能导致视觉重心偏移] → 实现时在 390/1264/1920 三档截图核对，必要时把字距降一档。
- [描边动画在 reduce 模式下若只写 `animation: none` 会停在初始 `dashoffset`] → 必须在 reduce 分支显式写回最终态。
- [状态行依赖数据库，静态化后可能与实际不同步] → 与首页同样的 60s `revalidate`，并接受这个延迟；不做客户端拉取（否则页面就要 JS）。
- [放大 favicon 图形到 96px 后，原本为 16px 调的比例可能显粗] → 放大版单独调整描边宽度与圆角（不是直接缩放位图），实现时以截图为准。

## Migration Plan

纯新增路由，无数据迁移、无接口变更。

1. 新增 `app/welcome/page.tsx`、`components/BrandMark.tsx`，样式加进 `app/redesign.css` 的 `.page-welcome` 段落。
2. 三档宽度 + reduce 动效 + 无 JS 各验一次；`tsc` 与 `build` 通过后提交。
3. 回滚：删除该路由与样式段即可，不影响任何既有页面。
