# Proposal

## Why

现在的首页直接进账本：一句定位、一条条日期、右侧栏。对常来的读者这很好——打开就能读。但它不是"门面"：第一次从别处点进来的人，看到的是**目录**而不是**这是什么地方**；分享给别人的落地页也只有一排标题。

站点缺一个可以单独发出去、三秒内说清"谁在写、写什么、要不要进去"的页面。

## What Changes

- 欢迎页落在**根路径 `/`**：一屏式的门面。原「按时间倒排」的账本首页搬到 `/blog`，旧地址 `/welcome` 用 301 收口到 `/`。
- 视觉方向是**白色赛博朋克**：冷白纸面 + 极低对比的细网格 + 一条电蓝、一条洋红，只落在"可点的东西"和站点标记的两个笔画上；靠字号、留白与一次入场动效撑住，不靠发光。
- 页面固定为这一套白色，**不跟随**站点六套主题（博客内部仍按主题走）。
- 内容只有四件事：站点标记、字标、一句定位、进入与两个次要入口；再加一行来自数据库的真实状态（文章数 / 标签数 / 最近更新）。
- 动效只有一次入场序列（网格淡入 → 标记描边 → 光标块落下 → 字标逐字 → 定位句与按钮），加一处 1.2s 步进闪烁的光标；`prefers-reduced-motion` 下全部静态呈现。
- 纯 CSS 动效，不引入新依赖，不新增客户端 JS（页面保持服务端渲染、可静态化）。

## Capabilities

### New Capabilities

- `welcome-page`: 欢迎页契约 —— 路由与入口、一屏内容与文案、固定白色配色与"霓虹只用于交互"的用色纪律、一次性入场动效与减弱动效降级、真实状态行的数据来源、以及不跟随站点主题的隔离规则。

### Modified Capabilities

（无。`site-shell`、`theme-system` 的现有契约不变：欢迎页只是新增一条路由，页头页脚与六套主题在其它页面照旧。）

## Impact

- **代码**：`app/page.tsx` 改为欢迎页（服务端组件，`revalidate` 与列表页一致）、原首页移到 `app/blog/page.tsx`、`next.config.ts` 增加 `/welcome` → `/` 的 301、`components/SiteNav.tsx` 加「文章」项、`components/BrandMark.tsx` 复用 favicon 图形做成可描边 SVG；样式加进 `app/redesign.css` 的 `.page-welcome` 段落。
- **数据**：只读查询文章数、标签数、最近发布时间，与列表页现有查询同类，不新增表、不改 schema。
- **不涉及**：认证、后台、ISR 策略变更、部署配置。
- **验证口径**：`npx tsc --noEmit` 与 `npm run build` 通过；`/` 200 渲染欢迎页、`/blog` 200 渲染列表、`/welcome` 301 到 `/`；1920 / 1264 / 390 三档无横向滚动；`prefers-reduced-motion: reduce` 下无动画且内容完整；`html[data-theme]` 在六套主题间切换时欢迎页外观不变。
- **不在本次范围**：替换首页、首次访问自动跳转、音效、3D/Canvas、滚动视差、真实插画素材。
