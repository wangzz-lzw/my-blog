# Spec Delta

## Purpose

定义博客如何渲染与呈现 Markdown 内容：代码块高亮与复制、标题锚点、外链行为、换行规则，以及各渲染入口之间的一致性。

## ADDED Requirements

### Requirement: 代码块语法高亮

带语言标记的围栏代码块 SHALL 以语法高亮渲染，且高亮在服务端渲染时完成，不依赖客户端 JS。

#### Scenario: 带语言的代码块
- **WHEN** 文章包含 ```js 或 ```python 围栏代码块
- **THEN** 代码按该语言着色（关键字/字符串/注释等使用主题色），且刷新页面无闪烁、无客户端重新计算

#### Scenario: 无语言或未知语言的代码块
- **WHEN** 围栏代码块未写语言、或语言不受支持
- **THEN** 代码以等宽字体原样渲染，无报错、无高亮，不影响页面其余部分

### Requirement: 代码卡复制

每个代码块 SHALL 提供一键复制其源码的控件；复制成功后给出可感知的反馈。

#### Scenario: 点击复制
- **WHEN** 访客点击代码卡上的复制控件
- **THEN** 代码文本写入剪贴板，控件短暂显示「已复制」类反馈后恢复

#### Scenario: 剪贴板不可用
- **WHEN** 浏览器拒绝剪贴板 API（如非安全上下文）
- **THEN** 降级为选中文本并提示，页面不报错

### Requirement: 标题锚点

每个标题 SHALL 拥有稳定的 id，访客可通过 URL 片段（#锚点）直达；悬停时显示可点击的锚定链接。

#### Scenario: 片段直达
- **WHEN** 打开形如 /posts/x#某标题 的 URL
- **THEN** 页面定位到对应标题处

#### Scenario: 重名标题
- **WHEN** 同一文章出现两个同名标题
- **THEN** 二者 id 唯一（自动加后缀），片段直达各自不混淆

### Requirement: 外链行为

指向站外域名的链接 SHALL 在新标签页打开并带有与站内链接可区分的视觉标记；站内链接保持当前页跳转。

#### Scenario: 站外链接
- **WHEN** 正文中的链接指向当前域名以外
- **THEN** 链接在新标签页打开（含 rel 安全属性），并有区别于站内链接的样式（如图标或下划线色）

#### Scenario: 站内链接
- **WHEN** 正文中的链接指向本博客路径
- **THEN** 在当前标签页跳转，无外链样式

### Requirement: 换行规则

段落内单个换行 SHALL 渲染为换行（与多数写作平台习惯一致），段落仍需空行分隔。

#### Scenario: 单换行
- **WHEN** 段落中两行文字之间只有一个换行
- **THEN** 渲染为两行，而不是合并成一行

### Requirement: GFM 表格保持可用

GFM 表格、删除线、任务列表 SHALL 继续正常渲染。

#### Scenario: 表格
- **WHEN** 文章包含 GFM 表格
- **THEN** 渲染为带边框表格，列对齐与表头样式正确

### Requirement: 渲染入口一致性

同一 Markdown 源码在文章详情页与任何其他渲染入口（如后台预览）SHALL 呈现一致（高亮、锚点、外链、换行行为相同）。

#### Scenario: 双入口对比
- **WHEN** 同一段 Markdown 分别在文章详情页与后台预览中渲染
- **THEN** 代码高亮、标题锚点、外链样式、换行行为完全一致
