# Tasks

## 1. 匹配与改写的纯逻辑

- [x] 1.1 新建 `lib/asset-localize.ts`：`findLocalImageRefs(markdown)` 找出所有图片引用并返回 `{ raw, target, start, end }`，**排除** `http(s)://`、`data:`、以 `#` 开头的锚点（判据必须与 `PostEditor` 现有那段正则一致）。验证：单测覆盖 `./images/a.png`、`a.png`、`../assets/b.jpg`、`https://x/y.png`、`data:image/png;base64,…`、`#anchor`、以及"替代文字含括号或中文"的用例，前三种被找出、后三种不被找出。
- [x] 1.2 实现 `rewriteRefs(markdown, mapping)`：返回 `{ content, replaced, unmatched }`，从后往前替换避免下标错位；未命中的引用原样保留并进入 `unmatched`。验证：单测断言"3 处引用只匹配 2 张 → 替换 2 处、unmatched 长度 1、未命中的文本逐字不变"；"替代文字与周围正文不被改动"用 `![系统架构图](./a.png) 前后文` 断言。
- [x] 1.3 验证幂等与重复调用：对已替换过的正文再次调用 `findLocalImageRefs` 应找不到本地引用（因为已是 `/img/…`）。验证：单测对 `rewriteRefs` 的输出再跑一次 `findLocalImageRefs`，结果长度为 0。

## 2. 导入入口改造

- [x] 2.3 只导入文档、不提供图片时，行为与改动前一致（本地引用原样保留）。验证：单文件导入一份含 3 处本地引用的 md，正文里 3 处引用逐字未变。

## 3. 上传与原子性
