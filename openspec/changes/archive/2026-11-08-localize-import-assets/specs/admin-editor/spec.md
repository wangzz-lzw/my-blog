# Spec Delta

## MODIFIED Requirements

### Requirement: 全屏内只保留写作必需内容

全屏状态 SHALL 只呈现正文编辑区与实时预览及其必需控件（Markdown 工具栏、编辑/分屏/预览切换、字符与行数统计、退出控件）；标题、slug、标签、封面、摘要等元信息 MUST 不可见。Markdown 工具栏 MUST NOT 包含独立的「插入图片」按钮——图片通过粘贴或拖入正文进入，与在正文中直接书写图片引用是同一条路径。

#### Scenario: 元信息不可见
- **WHEN** 编辑器处于全屏状态
- **THEN** 页面上看不到标题输入、slug、标签、封面、摘要字段，也看不到「立即发布」与保存按钮

#### Scenario: 保留当前视图模式
- **WHEN** 在「编辑」视图下进入全屏
- **THEN** 全屏后仍是「编辑」视图；进入前若为「分屏」则仍为分屏，并各自铺满高度、独立滚动

#### Scenario: 工具栏不含插入图片按钮
- **WHEN** 管理员查看 Markdown 工具栏
- **THEN** 看不到「插入图片」按钮，但粘贴截图或把图片拖进正文仍会自动上传并插入引用

## REMOVED Requirements

### Requirement: 工具栏的插入图片按钮

**Reason**: 该按钮做的事与「粘贴 / 拖入图片」完全重合（两者走同一个上传函数），却多一次点击、
多一条要维护的路径。既然在正文里直接传图才是自然动作，独立入口是冗余。

**Migration**: 用两种方式代替——(1) 在正文里粘贴截图，或把图片文件拖进编辑区，会插入图片引用；
(2) 导入带本地图片的 Markdown 文档时，图片会被自动上传并替换引用。两者都不需要点击工具栏按钮。
