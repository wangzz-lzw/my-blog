# Proposal

## Why

欢迎页右侧在本轮之前是空的——只有点了「登录」才有东西。一屏的门面里，那一半是浪费的：既不告诉人"这里有什么可读的"，也不给任何入口。

首页账本已经能读文章，但门面需要的不是列表，是**氛围 + 入口**：让最新几篇以某种"围着中心绕"的方式摆在那里，看着像这台机器的活体部件，点进去就能读。

## What Changes

- 欢迎页右栏加一个**圆形轨道**：最新几篇文章的卡片均匀分布在一个圆上，整体缓慢自转（约 40 秒一圈），卡片自身反向旋转保持正立。
- **封面规则**：文章有 `cover` 就用封面图；没有封面就用**文字封面**——标题 + 标签排成一张纸色小卡（标题等宽字两三行、标签在底部），与本页的排版语言一致。
- 指针悬停或键盘聚焦时轨道**减速到 1/4**，离开恢复；卡片本身可点击直接进文章。
- 与登录面板**共存**：点「登录」时轨道缩小成右侧一条窄带（约 45% 缩放、降低不透明度）继续转，像背景件；关掉面板后回到原尺寸。两者不抢同一块区域。
- 降级：`prefers-reduced-motion` 下不自动转（仍按环形排布）；无 JS 时退化成纵向文章列表；≤980px 窄屏不启用轨道，直接显示为列表。
- 文章不足 5 篇时把列表补齐到 5 个槽位，重复项对辅助技术隐藏、不可聚焦，只作为视觉填充。

## Capabilities

### New Capabilities

- `welcome-orbit`: 欢迎页右栏环形文章导航的契约 —— 数据来源与数量、封面与文字封面的选择规则、环形排布与自转、悬停/聚焦减速、点击跳转、与登录面板的空间协调，以及减弱动效 / 无 JS / 窄屏三种降级形态。

### Modified Capabilities

（无。`welcome-page` 的内容与配色、`auth-panel` 的面板行为都不变；轨道只是新增一块右栏内容，并在面板打开时让位。）

## Impact

- **代码**：新增 `components/welcome/WelcomeOrbit.tsx`（客户端，GSAP 定位与旋转、悬停减速、与登录面板的事件协调）与文字封面组件；`app/page.tsx` 新增"最新 N 篇（含封面与标签）"的查询，把数据传给轨道，并把右栏改成 `stage`（轨道） + `slot`（登录面板）两层；`app/redesign.css` 增加轨道与文字封面的样式段。
- **数据**：一次只读查询（最多 6 篇已发布文章 + 标签），与首页同类，不改 schema。
- **依赖**：GSAP 已在依赖里，不新增包。
- **性能**：6 张卡片 + 两个无限 tween，成本极低；封面图用 `loading="lazy"`。
- **验证口径**：`tsc` 与 `build` 通过；有封面/无封面两种卡片各见一次；悬停减速、点击跳转、reduce 不转、无 JS 退化成列表、窄屏列表化；面板打开时轨道缩小且不遮挡面板。
- **不在本次范围**：拖拽旋转、滚轮切换、3D 透视/倾斜、卡片翻转、无限加载更多文章。
