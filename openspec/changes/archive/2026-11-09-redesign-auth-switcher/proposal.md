# Proposal

## Why

欢迎页右侧的登录面板现在是"能用的"，但读起来像一张表单纸：两个 tab（登录 / 注册）之间除了指示条滑一下，内容只是淡入——`AuthPanel.tsx:104-108` 里那段 0.26s、`x: 12` 的位移几乎看不见。更糟的是两张表单**高度差很大**（登录 2 个字段，注册 5 个字段 + 邮箱验证码），
`auth-forms` 用 `min-height = max(两块高度)` 把容器撑到注册的高度，于是停在登录页时下方空出一大片——面板看起来"没做完"。

`app/specs/auth-panel/spec.md` 的「切换与开合的动效」其实已经写了"内容横向交叉、面板高度平滑变化"，
但实现只做到"位移 + 淡入"、高度是静态撑开。**这是规格与实现不符**，不是你这次才提出的新需求。

另外 `/login` 与 `/register` 是两个独立页面，切换要整页跳转：`LoginForm` 与 `RegisterForm` 各自套一个 `GsapReveal` 卡片，
互相之间用 `<Link>` 连。在欢迎页面板里切换是就地换 tab，跳去独立页却变成整页刷新——
同一件事两套体验。

## What Changes

- **切换动画改成横向换页**：两张表单同处一条横向轨道，切换时当前页向左滑出、目标页从右侧滑入，方向感明确（"往前翻"）。指示条同步位移并带一点跟随延迟，不再是两条各自动的动画。
- **容器高度跟随内容变化**：切到字段少的登录页时面板收窄，切到注册页时展开；高度用测量后的实际值过渡，替代现在"永远按最高的那块撑开"。
- **注册拆成两步**：第一步用户名 + 邮箱 + 验证码，第二步设密码与确认密码。带步骤指示（1 / 2）与"上一步"。这样面板高度差被压平，也让 5 个字段不再一口气堆满一屏。
- **独立页也换成同一套**：`/login` 与 `/register` 不再各自渲染一张卡片，改用同一个能就地切换的外壳；两个页面之间切换不再整页跳转（保留 URL 同步）。
- **面板视觉重做**：现在是一个纸白方块加两个对角括号，与欢迎页的白赛博语言关系很弱。改成用欢迎页已有的 `--w-signal` / 网格 / 扫描线语言，让它在门面里站得住。
- **保留**：Esc 关闭、焦点进第一个输入框、关闭后焦点归还触发按钮、两个 tab 的输入内容在切换后仍然保留、`prefers-reduced-motion` 下取消所有位移。

## Capabilities

### New Capabilities

（无。这是一次在既有能力内部的重做，没有引入新的系统行为。）

### Modified Capabilities

- `auth-panel`: 重写「切换与开合的动效」——从"位移 + 淡入"改为"横向交叉 + 高度跟随"，并把"高度不跟随内容"这个实现与规格不符的点修正。
  同时修改「登录 / 注册 tab 切换」以容纳两步注册（tab 内还有步骤，步骤不进 URL）。
- `welcome-page`: 「入场动效只有一次」这条与本变更的关系需要确认——面板在页面入场之外还有自己的切换动效，两者不冲突，但要在该要求里说清边界。

## Impact

- **组件**：改 `components/welcome/AuthPanel.tsx`（横向轨道 + 高度测量 + 两步注册）、`components/auth/RegisterFields.tsx`（拆成两段，暴露步骤状态）、`components/LoginForm.tsx` / `components/RegisterForm.tsx`（改用共享外壳）、`app/(site)/login/page.tsx` 与 `app/(site)/register/page.tsx`（保持 URL 语义）、`app/globals.css` 与 `app/redesign.css`（面板与切换动画样式）。
- **依赖**：无新增。动画继续用已在用的 GSAP（`AuthPanel` 现在已经 import 了它）。
- **行为面**：注册从"一次提交 5 个字段"变成"两步提交"，但**接口不变**——仍是最后一步一次性 `POST /api/register`（用户名 + 邮箱 + 验证码 + 密码）。验证码在第一步取，第二步才提交，因此中间存在"码已发出但还没注册"的时间窗，与现状一致。
- **风险**：两步注册改变了注册流程的心智模型，需要确认用户能随时回到第一步改邮箱；横向轨道在窄屏（单栏）下要退化为什么需要明确；面板高度过渡期间不能出现滚动条抖动；`/login` 与 `/register` 改成共享外壳后要保证直接访问任一 URL 都落到正确的 tab。
- **验证口径**：真实浏览器里登录↔注册切换有可见的方向性位移且高度跟随；两步注册能走通并成功创建账号；直接访问 `/login` 与 `/register` 分别落在对应 tab；切换后切回仍保留已输入内容；Esc 与焦点归还仍有效；`prefers-reduced-motion` 下无位移；`tsc` 与 `build` 通过。
- **不在本次范围**：第三方登录、忘记密码、记住我、验证码改成图形码、把注册改成三步以上、欢迎页面板以外的其它浮层动效、登录态下的面板内容（面板只在未登录时出现）。
