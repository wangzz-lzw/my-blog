# Spec Delta

## Purpose

定义欢迎页右栏那个环形文章导航：它展示什么、怎么转、封面的取舍规则、怎么与登录面板共处，以及在没有动画、没有 JS、屏幕很窄时退化成什么。

## ADDED Requirements

### Requirement: 环形排布与自转

右栏 SHALL 把最新几篇文章的卡片均匀排布在一个圆上，并整体缓慢自转（一圈约 40 秒，线性、不停顿）；卡片自身 MUST 反向旋转以保持文字正立。

#### Scenario: 常态
- **WHEN** 打开 `/` 且文章数不少于 2
- **THEN** 卡片沿圆周均布，整体绕圆心匀速自转，卡片正面始终朝上，不会歪着走

#### Scenario: 数量不足
- **WHEN** 已发布文章少于 5 篇
- **THEN** 列表被补齐到 5 个槽位；重复项对辅助技术隐藏、不可聚焦，只作为视觉填充

### Requirement: 封面选择规则

每张卡片 SHALL 优先使用文章封面图；文章没有封面时 MUST 使用文字封面：文章标题 + 该文章的标签，排成一张纸色小卡。

#### Scenario: 有封面
- **WHEN** 文章设置了 `cover`
- **THEN** 卡片以封面图为主体，等比裁切填满卡面，不拉伸变形

#### Scenario: 无封面
- **WHEN** 文章没有封面
- **THEN** 卡片显示文字封面：等宽字标题（超长截断为两到三行）+ 底部标签，纸色底与发丝线描边

### Requirement: 悬停与聚焦减速

指针悬停或键盘聚焦到任意卡片时，轨道 SHALL 减速（约常态的四分之一）；移开或失焦后恢复原速。

#### Scenario: 悬停
- **WHEN** 指针移入某张卡片
- **THEN** 自转明显变慢，卡片可从容阅读；移开后回到原速

#### Scenario: 键盘聚焦
- **WHEN** 用 Tab 把焦点移到卡片上
- **THEN** 轨道减速或暂停，焦点环清晰可见

### Requirement: 点击进入文章

每张卡片 SHALL 是链接，点击进入对应文章；MUST 支持修饰键点击（新标签打开）。

#### Scenario: 点击
- **WHEN** 点击某张卡片
- **THEN** 进入该文章的详情页

#### Scenario: 新标签打开
- **WHEN** 按住 Cmd/Ctrl 点击卡片
- **THEN** 浏览器按默认行为在新标签打开，页面不拦截

### Requirement: 与登录面板共存

登录面板打开时，轨道 SHALL 缩小并降低存在感（缩放、下移或右移、降低不透明度），MUST NOT 遮挡面板或拦截其上的点击；关闭后 MUST 恢复原样。

#### Scenario: 打开登录
- **WHEN** 点击「登录」
- **THEN** 轨道缩成右侧一条窄带继续缓慢自转，登录面板完整可见可操作

#### Scenario: 关闭登录
- **WHEN** 关闭登录面板
- **THEN** 轨道回到原尺寸与位置

### Requirement: 减弱动效

`prefers-reduced-motion: reduce` 成立时，轨道 MUST NOT 自动旋转，但仍按环形排布静置；悬停减速等依赖旋转的行为不再生效。

#### Scenario: 减少动态效果
- **WHEN** 系统开启该偏好打开 `/`
- **THEN** 卡片静止在圆环上，不出现持续旋转

### Requirement: 无 JS 与窄屏退化为列表

没有 JavaScript 时，右栏 MUST 退化成一份纵向文章列表（可读、可点击）；视口宽度不超过 980px 时，轨道 MUST NOT 启用，同样以列表呈现。

#### Scenario: 禁用 JS
- **WHEN** 浏览器禁用 JavaScript 打开 `/`
- **THEN** 右栏是以文字封面形式呈现的文章列表，可正常点击进入

#### Scenario: 窄屏
- **WHEN** 在 390px 宽的视口打开 `/`
- **THEN** 不出现环形排布，文章以纵向列表排在文案下方，无横向滚动

### Requirement: 装饰不干扰语义

轨道容器 MUST NOT 成为页面主导航（它是展示性的入口集合）；重复填充项与装饰元素对辅助技术隐藏；页面仍只有一个 `h1`。

#### Scenario: 屏幕阅读器
- **WHEN** 屏幕阅读器读取页面
- **THEN** 只读到真实文章链接（带标题作为可读名称），重复填充项不被朗读
