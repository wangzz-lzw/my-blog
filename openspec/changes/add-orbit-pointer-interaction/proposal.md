# Proposal

## Why

3D 环绕现在只有两个反应：悬停减速、点卡片跳转。它像一件摆在橱窗里自转的展品——好看，但**你碰不到它**。鼠标移上去除了变慢之外什么都不会发生，拖动不会转，滚轮不会切，卡片也不朝你迎过来。

既然它是这块地方的主要视觉，就应该能上手拨弄。

## What Changes

- **拖拽旋转 + 惯性**：按住左右拖，环跟着手转；松手后带惯性继续转一段再慢慢停，约 1.5 秒后重新接回自动自转（仍 40 秒一圈）。
- **指针倾斜**：指针在右栏移动时，整个环跟着做小幅 3D 倾斜（约 ±7°），像有只手电照着转。
- **悬停前推**：指针悬停的那张卡朝视线方向推出来（`translateZ` 前推 + 轻微放大），其余卡片略降不透明度，让"当前这张"成立。
- **滚轮吸附**：在环上滚动一格，环转到最近的卡位（8 格 → 每格 45°），停稳后恢复自动自转。
- **点击进入详情**：点卡片（含标题区域）跳转到对应文章；拖拽过程中的误触不会触发跳转。
- 触屏支持拖拽；`prefers-reduced-motion` 下关掉自转、惯性、倾斜，保留拖拽与吸附（瞬时无缓动）。

## Capabilities

### New Capabilities

- `orbit-interaction`: 3D 环绕的指针交互契约 —— 拖拽（含拖拽与点击的区分）、松手惯性与恢复自转的时序、指针倾斜的幅度上限、悬停前推与其余卡片让位、滚轮吸附的步长与作用范围，以及触屏与减弱动效下的降级。

### Modified Capabilities

（无。`welcome-orbit` 的排布、封面规则、自转周期不变；本变更只加"怎么被拨弄"。）

## Impact

- **代码**：`components/welcome/WelcomeOrbit.tsx` 从"一条自转 tween"改成**单旋转状态 + 三种驱动者**（自动 / 惯性 / 吸附），并加拖拽、倾斜、悬停前推的事件处理；`app/redesign.css` 补 `.orbit-tilt` 包裹层、悬停前推与拖拽光标样式。
- **依赖**：不新增。拖拽用 Pointer Events 手写（GSAP 的 Draggable/Inertia 属于付费或额外包，不引）。
- **行为变化**：右栏在指针悬停时会吃掉滚轮（为了吸附切换），需要明确只在指针位于环区域内时拦截；页面其余部分滚动不受影响。
- **验证口径**：`tsc` 与 `build` 通过；拖拽后确实停住并恢复自转；拖拽超过阈值不触发跳转、未拖动时点击能进详情；倾斜幅度可见但不超过 ±7°；滚轮一格对应 45°；390px 与 reduce 下行为降级正确。
- **不在本次范围**：惯性物理曲线调参面板、键盘左右键切卡（已有 Tab 聚焦）、卡片翻转/翻转看详情、拖动改变环的倾斜轴。
