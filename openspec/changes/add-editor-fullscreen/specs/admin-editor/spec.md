# Spec Delta

## Purpose

定义后台文章编辑器在写作时的视图契约：正文与预览的视图切换、全屏写作的进入与退出、全屏内的极简内容与状态保持，以及在原生全屏不可用时的降级行为。

## ADDED Requirements

### Requirement: 全屏写作入口

文章编辑器（新建与编辑）SHALL 提供可识别的全屏控件，控件如实反映当前是否处于全屏。

#### Scenario: 进入全屏
- **WHEN** 管理员在编辑器页点击全屏控件
- **THEN** 编辑器进入全屏写作状态，控件状态变为「已全屏（可退出）」

#### Scenario: 控件常驻可见
- **WHEN** 管理员打开新建或编辑文章页
- **THEN** 全屏控件在未进入全屏时可见、可点击，且不与保存/发布等主要动作争夺注意力

### Requirement: 原生全屏优先与自动降级

进入全屏时系统 SHALL 优先请求浏览器原生全屏；若运行环境不支持或请求被拒绝，SHALL 改为在页面内铺满整个视口，且 MUST NOT 抛出未捕获错误或停留在半途状态。

#### Scenario: 支持原生全屏
- **WHEN** 浏览器支持元素级全屏且请求被接受
- **THEN** 全屏元素为编辑器容器自身，界面按全屏布局渲染

#### Scenario: 不支持或被拒绝
- **WHEN** 浏览器不支持元素级全屏（如 iOS Safari）或请求被拒绝
- **THEN** 编辑器仍铺满整个视口（覆盖后台侧栏与页头），控件仍显示为「已全屏」，控制台无未捕获错误

### Requirement: 全屏内只保留写作必需内容

全屏状态 SHALL 只呈现正文编辑区与实时预览及其必需控件（Markdown 工具栏、编辑/分屏/预览切换、字符与行数统计、退出控件）；标题、slug、标签、封面、摘要等元信息 MUST 不可见。

#### Scenario: 元信息不可见
- **WHEN** 编辑器处于全屏状态
- **THEN** 页面上看不到标题输入、slug、标签、封面、摘要字段，也看不到「立即发布」与保存按钮

#### Scenario: 保留当前视图模式
- **WHEN** 在「编辑」视图下进入全屏
- **THEN** 全屏后仍是「编辑」视图；进入前若为「分屏」则仍为分屏，并各自铺满高度、独立滚动

### Requirement: 三种退出路径互通

系统 SHALL 支持 Esc、界面上的退出控件、浏览器自身退出（原生全屏的 Esc 或系统快捷键）三种退出方式；任一路径退出后，控件状态与页面布局 MUST 立即同步。

#### Scenario: Esc 退出
- **WHEN** 全屏状态下按 Esc
- **THEN** 退出全屏并恢复进入前的页面布局；原生全屏由浏览器处理退出，界面状态随之一致

#### Scenario: 按钮退出
- **WHEN** 全屏状态下点击退出控件
- **THEN** 退出全屏并恢复进入前的页面布局

#### Scenario: 从浏览器退出
- **WHEN** 原生全屏下用户用浏览器/系统方式退出全屏（而非页面控件）
- **THEN** 页面控件立即回到「未全屏」，不出现按钮显示「退出全屏」但实际已退出壳层的错位

### Requirement: 进出全屏不丢内容

进入与退出全屏 MUST NOT 丢弃已输入内容、当前视图模式与编辑位置；未保存的内容保持原样。

#### Scenario: 退出后内容仍在
- **WHEN** 在全屏中继续输入正文后退出全屏
- **THEN** 标题、正文、标签、摘要与进入前输入的其余内容全部保留，输入焦点回到正文编辑区

#### Scenario: 视图模式保持
- **WHEN** 以「预览」视图进入全屏并退出
- **THEN** 退出后仍是「预览」视图，不回落到默认视图

### Requirement: 站内回退退出后恢复页面

站内铺满退出后 SHALL 恢复后台侧栏与页头，并解除对页面滚动的锁定。

#### Scenario: 滚动恢复
- **WHEN** 通过站内回退进入全屏再退出
- **THEN** 页面可以正常滚动，后台侧栏与页头重新出现，编辑器回到正常文档流

### Requirement: 全屏控件的可访问性

全屏控件 MUST 有可读名称并暴露当前状态，键盘可达且有可见焦点。

#### Scenario: 键盘操作
- **WHEN** 用 Tab 移动到全屏控件并按 Enter 或空格
- **THEN** 进入或退出全屏，控件名称与状态随之更新，焦点保持可见

#### Scenario: 状态可被辅助技术识别
- **WHEN** 屏幕阅读器读取该控件
- **THEN** 能获得「进入全屏写作」或「退出全屏」这类明确名称，以及当前是否全屏的状态

### Requirement: 窄屏下全屏仍可用

视口宽度不超过 720px 时，全屏写作 SHALL 仍可用：工具栏可换行，正文与预览占满可用高度，页面不得出现横向滚动。

#### Scenario: 手机进入全屏
- **WHEN** 在 390px 宽视口进入全屏写作
- **THEN** 正文区占满高度且可滚动输入，工具栏控件不重叠，无横向滚动条，可正常退出
